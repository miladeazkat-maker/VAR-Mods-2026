# ⚽ PES Analytics & Broadcast Overlay Suite

An open-source, Python-driven modular analytics and match presentation suite for **Pro Evolution Soccer (PES)**. 

This project bridges real-time RAM reading with custom renderers to bring modern broadcast technologies and advanced match analytics directly into PES. Built as a **community-first initiative**, we welcome developers, modders, and football gaming enthusiasts to contribute, optimize, and expand this suite!

---

## 🌟 Featured Modules

* 📐 **SAOT Mod (Semi-Automated Offside Technology):** Real-time positional tracking and dynamic 3D offside line generation.
* 🥅 **GLT Mod (Goal-Line Technology):** High-precision goal-line decision overlays and instant replay visuals.
* 🔥 **HeatMap Mod:** Dynamic tactical heatmaps tracking player positioning and team influence live during matches.
* 🎥 **RefereeView Mod:** Immersive referee-perspective overlay and dynamic camera view framing.
* 📈 **MomentumMatch Mod:** Real-time match pressure indicators and momentum graph analytics.

---

## 🛠️ Built With & Architecture
* **Language:** 100% Raw Python
* **Core Mechanisms:** Direct RAM Memory Reading, Custom Overlay Rendering & Mathematical Systems
* **Target Games:** PES 2017 / PES 2021 / Football Life
